Need the Template?

Download the official template so your columns match exactly what the importer expects. Do not add Username or Password columns -- those are generated automatically (Username = Email, Password = CNIC).

Download Template (.xlsx)
Expected Columns (exact order)
  • Full Name
  • CNIC (13 digits, e.g. 42101-1234567-1)
  • Station (must be a valid PIA station)
  • Cell no
  • Email
  • Qualification
  • Major
  • University
  • Department (must match an existing department exactly)
  • Division/Section (must match an existing division/section under that department)
  • Internship Start Date
  • Internship End Date
  • Documents Status (Complete / Pending / In Progress)
  • Certificate Status (Pending / Generated / Issued)

Extra columns and extra whitespace are ignored. Empty rows are skipped. Rows with missing/invalid data, an unknown station, an unknown Department/Division/Section, or a duplicate CNIC/Email are rejected with a clear reason -- the rest of the file still imports. Department and Division/Section must already exist (Admin → Departments) -- free-text placements are no longer accepted. A User account is created automatically for every imported intern (Username = Email, Password = CNIC, Role = Intern, password hashed). No emails are sent for bulk imports.
